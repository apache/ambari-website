# Ambari 邮件列表 {#ambari-mailing-lists}

欢迎访问 Apache Ambari 邮件列表页面。这些邮件列表是 Ambari 社区的主要沟通渠道，您可以在此讨论开发、提问、报告问题并了解项目活动的最新动态。

## 可用的邮件列表 {#available-mailing-lists}

以下是 Apache Ambari 项目设立的邮件列表。每个列表都提供订阅、取消订阅、发布消息和访问存档的链接。

| 名称 | 描述 | 订阅 | 取消订阅 | 发布 | 存档 |
|-------------------|-----------------------------------------------------------------------------|-----------------------------------------------|-----------------------------------------------|---------------------------------------------|--------------------------------------------------------------|
| 用户列表 | 关于使用 Ambari 的一般问题、讨论和支持。 | [订阅](mailto:user-subscribe@ambari.apache.org) | [取消订阅](mailto:user-unsubscribe@ambari.apache.org) | [发布](mailto:user@ambari.apache.org) | [查看存档](https://mail-archives.apache.org/mod_mbox/ambari-user/) |
| 开发列表 | 关于 Ambari 开发和贡献的技术讨论。 | [订阅](mailto:dev-subscribe@ambari.apache.org) | [取消订阅](mailto:dev-unsubscribe@ambari.apache.org) | [发布](mailto:dev@ambari.apache.org) | [查看存档](https://mail-archives.apache.org/mod_mbox/ambari-dev/) |
| JIRA 列表 | 关于 Ambari JIRA 问题和工单的通知与讨论。 | [订阅](mailto:issues-subscribe@ambari.apache.org) | [取消订阅](mailto:issues-unsubscribe@ambari.apache.org) | [发布](mailto:issues@ambari.apache.org) | [查看存档](https://mail-archives.apache.org/mod_mbox/ambari-issues/) |

| 提交列表 | 关于代码提交和仓库更新的通知。 | [订阅](mailto:commits-subscribe@ambari.apache.org) | [取消订阅](mailto:commits-unsubscribe@ambari.apache.org) | [发布](mailto:commits@ambari.apache.org) | [查看存档](https://mail-archives.apache.org/mod_mbox/ambari-commits/) |

## 如何参与 {#how-to-participate}

1. **选择邮件列表**：选择符合您兴趣的列表（例如用户支持、开发或问题跟踪）。
2. **订阅**：点击“订阅”链接，并按照确认邮件中的说明操作。
3. **发布消息**：订阅后，您可以向列表的发布地址发送邮件，以发起或参与讨论。
4. **访问存档**：使用存档链接浏览过去的讨论，以供参考或了解背景。

## 指南 {#guidelines}

- 在所有通信中保持尊重和专业。
- 发帖前搜索存档，避免提出重复问题。
- 请求帮助时包含相关详细信息（例如 Ambari 版本、环境）。
- 对于错误报告或功能请求，请考虑使用 [Ambari JIRA](https://issues.apache.org/jira/projects/AMBARI)，而不是邮件列表。

## 故障排除 {#troubleshooting}

如果遇到邮件列表问题：

1. **订阅问题**：
   - 确保已通过发送给您的邮件确认订阅。
   - 检查垃圾邮件文件夹中的确认邮件。
   - 联系列表管理员（例如 `user-help@ambari.apache.org`）寻求帮助。

2. **发布问题**：
   - 确认您使用已订阅的电子邮件地址发送邮件。
   - 确保您的消息符合列表指南，以免进入审核流程。

3. **存档访问**：
   - 如果无法访问存档链接，请稍后重试或联系 Apache 邮件列表支持团队。

## 重要说明 {#important-notes}

- 邮件列表由 Apache 托管，并遵循 Apache 软件基金会指南。
- 存档公开可访问，因此请避免分享敏感信息。
- 开发和 JIRA 等活跃列表的邮件量较大；请考虑使用摘要模式接收订阅内容。

如需其他帮助，请参阅 [FAQ](faq.md)，或在 [Ambari JIRA](https://issues.apache.org/jira/projects/AMBARI) 中提交问题。
